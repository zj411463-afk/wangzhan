# EmojiNook design system

Direction: Miro-inspired, playful editorial utility. The interface stays bright and easy to scan while the copy tool remains the focus.

## Tokens

- Ink: `#1c1c1e`
- Brand yellow: `#ffd02f` (wordmark, accents, and supporting panels—not the primary CTA)
- Supporting cards: pale yellow `#fff3b5`, rose `#ffd7e0`, coral `#ffb5a7`, teal `#a9e7dc`
- Background: white; secondary surface `#f7f7f8`
- Radius: `22px` cards, pill controls
- Type: system sans-serif; bold, tightly tracked display headings
- Primary action: black pill with white text

## Interaction rules

- Every copy card is a real button and supports keyboard focus.
- Controls have at least a 44px touch target.
- Copy feedback uses an `aria-live` toast.
- Mobile uses one card per row and hides nonessential header navigation.
