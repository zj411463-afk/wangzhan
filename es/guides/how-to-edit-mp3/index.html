Cómo editar MP3: recortar, dividir, escuchar y guardar

Conservar una frase, dividir capítulos y cambiar el sonido son tareas distintas. Sonic Cutter recorta y divide localmente; no ofrece volumen, mezcla, reducción de ruido, fundidos ni conversión.

Abrir herramienta de audio

1. Elegir recortar o dividir

Usa el cortador para un pasaje continuo y el divisor para varios archivos consecutivos. Elige un MP3 normal; renombrar una descarga protegida no la hace compatible.

Divisor MP3 online: dividir por duración o marcas de tiempo

2. Definir los límites

Para recortar usa la onda o los tiempos de inicio y fin. Para dividir indica segundos o marcas como 0:30, 1:00. Se conserva la parte final y se muestran los tiempos ajustados a cuadros.

3. Escuchar antes de guardar

El cortador reproduce la selección y el divisor el MP3 realmente exportado. Comprueba la primera nota y el final de las frases. Las dependencias entre cuadros pueden afectar el inicio.

4. Guardar y comprobar

Descarga un pasaje, las partes o un ZIP. Busca en Descargas o Archivos y prueba otro reproductor si hace falta. El original no cambia.

Cuándo usar un editor completo

El volumen, la reducción de ruido, las uniones y los fundidos cambian las muestras y suelen necesitar otra codificación para MP3. Usa un editor adecuado. Copiar cuadros no mejora la calidad original.
